# Plan: 5 Zeitalter

Entschieden von Emin am 2026-10-26: **Steinzeit → Antike → Mittelalter → Industrie → Moderne**.
Neue Städte beginnen in der Steinzeit. Mit jedem Zeitalter kommen mehr Waren und Gebäude dazu.
Alte Spielstände (vor Version 44) laden weiter und stehen im Mittelalter.

Aufgestiegen wird im Fenster „Zeitalter“ (oben auf das Zeitalter tippen). Dafür braucht man
genug Einwohner und bezahlt Waren. Gebäude aus früheren Zeitaltern bleiben erhalten und arbeiten weiter.

## 1 · 🪨 Steinzeit (Start)

**Waren:** 🪵 Holz, 🪨 Stein, 🍞 Nahrung, 💡 Wissen – kein Geld.

| Gebäude | Was es macht |
|---|---|
| 🛣️ Pfad (Straße) | kostet hier Holz statt Geld |
| 🛖 Hütte | Wohnraum für 3 Einwohner |
| 🫐 Sammlerin | Beeren und Pilze (Nahrung), besser im Wald, im Winter wenig |
| 🏹 Jägerlager | Nahrung durch Jagd, besser am Wald |
| 🪓 Holzfäller | Holz, besser im Wald |
| 🪨 Steinsammler | Stein, besser am Berg |
| 🔥 Feuerstelle | Freizeit für Hütten im Umkreis |
| 🎨 Höhlenmaler | Wissen für die Forschung |
| 💧 Wassertrog | löscht Brände in der Nähe, wird in der Antike zur Feuerwache |

**Forschung:** Steinwerkzeuge, Speere, Flechtkörbe, Lehmhütten.

Land kostet Holz und Nahrung. Keine Steuern, keine Händler, keine Banditen, keine Seuchen (erst ab der Antike, wenn es Brunnen gibt).

**Aufstieg zur Antike:** 25 Einwohner · 100 Holz, 80 Stein, 100 Nahrung.

## 2 · 🏺 Antike

**Neu:** 💰 Geld (Steuern, Markt), 🧱 Ziegel, 🧶 Wolle.

Haus, Farm, Fischerhütte, Sägewerk, Steinbruch, Markt, Lagerhaus, Brücke, Park, Brunnen, Feuerwache,
Schreibstube, Wachhaus, Mauer, Schäferei, Ziegelei, Brunnenplatz (Forum).

**Aufstieg zum Mittelalter:** 40 Einwohner · 400 Geld, 30 Wissen, 100 Stein, 15 Ziegel.

## 3 · 🏰 Mittelalter

**Neu:** 🪜 Bretter, 🥖 Brot, 🍺 Bier, 🧵 Stoff, ⛓️ Eisen, 🛠️ Werkzeug.

Erzmine, Schreinerei, Bäckerei, Brauerei, Weberei, Schmiede, Schule, Bibliothek, Wachturm,
Krankenhaus, Rathaus, Kathedrale.

## 4 · 🏭 Industrie (kommt später)

**Neue Waren (Vorschlag):** ⚫ Kohle, 🔩 Stahl, 📦 Fabrikwaren.

| Gebäude | Was es macht |
|---|---|
| ⚫ Kohlebergwerk | Kohle, am Berg |
| 🔥 Stahlwerk | Eisen + Kohle → Stahl |
| 🏭 Fabrik | Stoff/Bretter + Stahl → Fabrikwaren |
| 🏢 Mietshaus | viel Wohnraum auf wenig Fläche |
| 🚂 Bahnhof | Handel ohne Karrenweg, mehr Geld |
| 👮 Polizeiwache | Sicherheit, ersetzt Wachhaus |
| 🏛️ Wahrzeichen: Großer Bahnhof oder Rathausturm | |

## 5 · 🏙️ Moderne (kommt später)

**Neue Waren (Vorschlag):** ⚡ Strom, 🧱 Beton, 💻 Elektronik.

| Gebäude | Was es macht |
|---|---|
| ⚡ Kraftwerk / ☀️ Solarpark | Strom – Gebäude arbeiten mit Strom schneller |
| 🏗️ Betonwerk | Stein → Beton |
| 🏙️ Hochhaus | sehr viel Wohnraum |
| 🛒 Supermarkt | Versorgung, Händler |
| 🎓 Universität | viel Wissen und Bildung |
| 🏟️ Stadion | Freizeit für die ganze Stadt |
| ✈️ Wahrzeichen: Flughafen | |
